資料與儲存

🔧 技術說明(點擊展開)
  • 架構:單一 HTML、純前端、無後端。Leaflet 1.9.4 由 unpkg CDN 載入;底圖為 OpenStreetMap 圖磚,無需 API Key。
  • 定位:navigator.geolocation.getCurrentPosition(enableHighAccuracy:true,逾時 20 秒)。須在 HTTPS 或 localhost 使用,並需使用者授權。精度(accuracy)以公尺記錄。室內多為 Wi-Fi/基站定位,誤差較大。
  • IndexedDB:資料庫 footprintDB v1,兩個 object store:places(keyPath id,索引 time、catId)與 categories(keyPath id)。預設分類 id 為 uncat。
  • 持久化:啟動及首次儲存時呼叫 navigator.storage.persist()。瀏覽器可能自動批准(如已安裝為 PWA、有書籤或常用),亦可能拒絕或提示;結果見上方狀態。navigator.storage.estimate() 顯示用量。即使已持久化,仍建議定期匯出 JSON 備份。
  • 時間:內部以 ISO 8601 UTC 字串(time)儲存;介面以本地時區顯示。日期篩選以本地日期比較。
  • JSON 格式:{app, version, exportedAt, categories:[{id,name,color}], places:[{id,name,lat,lng,acc,time,catId,note}]}。匯入時會驗證座標範圍,並自動補回缺失分類。
  • 目錄:篩選、排序、分頁皆於記憶體內完成(資料量數千筆內足夠)。頁碼在篩選變更時重設為 1。
  • Add to Home Screen:Chromium 瀏覽器監聽 beforeinstallprompt 顯示「安裝」按鈕;iOS Safari 無此事件,故顯示手動步驟(分享 → 加入主畫面)。已以獨立模式開啟時不顯示。本檔以 Blob 動態產生 manifest 與圖示。若要完整 PWA 安裝資格(尤其 Chrome),建議另加 manifest.json、圖示 PNG 與 sw.js。
  • 圖磚使用政策:OSM 公共圖磚僅適合輕度個人使用;若流量大,請改用自己的圖磚服務。
  • 安全:所有使用者文字均經 HTML 跳脫後才輸出,避免 XSS。
