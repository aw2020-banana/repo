🔧 技術架構

本應用為純靜態單檔案網頁，所有資源（HTML、CSS、JavaScript）整合在一個檔案中。資料儲存於瀏覽器的 IndexedDB，無需後端伺服器。

💾 資料持久化

使用 navigator.storage.persist() API 向瀏覽器請求持久化儲存權限，防止瀏覽器在空間不足時自動清除資料。IndexedDB 中的資料（包含壓縮後的圖片）會一直保留，除非手動清除。

📷 圖片壓縮

上傳圖片時使用 Canvas API 進行客戶端壓縮：全尺寸圖片限制最大寬度 800px（JPEG 品質 0.7），縮圖限制 200px（JPEG 品質 0.6）。大幅減少儲存空間佔用，同時保持良好視覺品質。每筆記錄最多儲存 10 張圖片。

📱 PWA 與離線支援

應用包含 manifest.json（透過 Blob URL 動態生成）與 beforeinstallprompt 事件監聽，支援「Add to Home Screen」安裝提示。所有資料操作（新增、編輯、刪除、搜尋）均在本地完成，完全離線可用。

📤 資料可攜性

支援 JSON 匯出/匯入功能，可完整備份所有記錄（包含圖片 base64 資料）。匯出格式包含版本號與時間戳，便於版本管理與跨裝置遷移。

🛡️ 隱私

所有資料完全儲存在本地瀏覽器中，不會上傳到任何伺服器。使用者擁有完全的資料控制權。

🌐 瀏覽器相容性

支援所有現代瀏覽器：Chrome 80+、Firefox 80+、Safari 14+、Edge 80+。部分功能（如 persist()）需 HTTPS 或 localhost 環境。

📐 響應式設計

桌面端使用資料表格顯示，平板及手機端自動切換為卡片佈局。所有互動元素針對觸控操作進行最佳化。
