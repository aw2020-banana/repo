技術說明

📦 IndexedDB 本地資料庫

所有吉他資料儲存在瀏覽器的 IndexedDB 中，是一種客戶端儲存方案，資料不會上傳到任何伺服器。IndexedDB 支援結構化資料儲存，包括 Blob（圖片）類型的資料。

🔒 Storage Persistence API

本應用使用 navigator.storage.persist() 向瀏覽器申請持久化儲存。一旦獲批，瀏覽器不會在空間不足時自動清除 IndexedDB 中的資料，確保你的吉他收藏安全。但請注意：清除瀏覽器資料或重裝瀏覽器仍會導致資料丟失，建議定期匯出備份。

📷 圖片壓縮技術

上載圖片時，系統會使用 Canvas API 自動壓縮：最大解析度限制為 1200x1200px，JPEG 品質設定為 0.7。這樣可以在保持合理畫質的同時大幅減少儲存空間佔用。每支吉他最多可上載 10 張圖片。

📤 JSON 匯入/匯出

匯出功能將所有吉他資料（包含圖片的 Base64 編碼）打包為 JSON 檔案。匯入時會讀取 JSON 並批量寫入 IndexedDB。匯入模式為「合併」，不會覆蓋現有資料（但相同 ID 的記錄會被更新）。

📱 離線可用 (Offline First)

本頁面使用 Service Worker 快取策略，首次載入後會快取頁面資源。之後即使在離線狀態下也能正常使用所有功能（新增、編輯、查詢等），所有操作均在本地完成。

🏠 安裝至主畫面 (PWA)

本應用支援 PWA（Progressive Web App）安裝。你可以將其安裝到裝置主畫面，像原生 App 一樣使用。安裝後會以獨立視窗開啟，提供更好的使用體驗。

📊 分页與篩選

列表預設每頁顯示 20 筆資料。篩選功能支援按品牌、狀態過濾，以及全文搜尋（搜尋標題、型號、備註欄位）。篩選在記憶體中執行，回應迅速。
