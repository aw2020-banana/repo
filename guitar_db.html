IndexedDB：本地瀏覽器資料庫，資料存於裝置，無需伺服器。支援離線讀寫，重啟後資料依然保留。
navigator.storage.persist()：向瀏覽器申請「持久化儲存」權限，防止瀏覽器在空間不足時自動清除資料。
Service Worker：背景執行的 JS Worker，攔截網路請求並回傳快取，實現完全離線功能。
圖片壓縮：上載時使用 Canvas API 將圖片縮小至最大 1200px 並轉為 JPEG 80% 品質，大幅減少儲存空間。
JSON 匯入/匯出：所有資料（含圖片 Base64）可完整匯出為 JSON，並可在其他裝置匯入還原。
