💡 架構與技術規格說明：

  • 儲存核心 (IndexedDB)： 使用瀏覽器內建非關聯式資料庫，支援事務（Transactions），適合大容量結構化數據及二進位/Base64 圖片儲存。
  • 持久化申請 (Storage Persistence)： 自動調用 navigator.storage.persist()。核准後，除非用戶手動清除，否則瀏覽器在磁碟不足時絕不會自動刪除此資料庫。
  • 圖片壓縮機制： 利用 HTML5 Canvas API 在前端將上傳圖片等比例限寬 800px 並進行 JPEG 75% 壓縮，單張圖片體積通常可縮減 80% 以上，防止過度佔用 IndexedDB 空間。
  • 全單檔案離線（Offline-Capable）： 本系統採用無依賴設計。對於進階 PWA 離線能力，本頁面整合了內聯 manifest。當部署在 HTTPS 環境時，即可解鎖完整「加入主畫面 (A2HS)」能力。
