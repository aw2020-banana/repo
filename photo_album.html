技術架構說明

⚡ 儲存層 — IndexedDB

相片以 Blob 形式直接存入 IndexedDB（Object Store: photos），無需伺服器，完全本機儲存。透過 IDBObjectStore 支援 CRUD 操作，讀取時用 URL.createObjectURL(blob) 轉成臨時 URL 渲染圖片。

IndexedDB v3 Blob 原始格式 IDBKeyRange 查詢

🔒 持久化儲存 — navigator.storage.persist()

一般情況下瀏覽器在磁碟空間不足時會自動清除 IndexedDB 資料。本 App 在啟動時呼叫 navigator.storage.persist()，取得「持久化」許可後，瀏覽器將保護此 origin 的資料不被自動清除，等同原生 App 的儲存保障。

需使用者授權 保護 IndexedDB

📱 Add to Home Screen — PWA

App 包含 Web App Manifest（manifest.json，此處以 Data URI 內嵌），宣告 display: standalone、icon、theme color。瀏覽器偵測到 beforeinstallprompt 事件後，右下角出現安裝橫幅。iOS Safari 用戶可透過分享選單手動加入主畫面。

Web App Manifest beforeinstallprompt standalone display

🔧 離線支援 — Service Worker

Service Worker（內嵌於此頁，以 Blob URL 動態注冊）攔截所有網路請求，採 Cache First 策略：優先從 Cache Storage 回應，失敗時才請求網路，確保完全離線可用。App Shell（HTML/CSS/JS）在首次載入時預快取。
