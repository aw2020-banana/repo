技術說明

資料層

使用 IndexedDB `guitars` object store，主鍵為 `id`，未來可再擴充更多索引或排序欄位。

單檔策略

HTML、CSS、JavaScript 與 manifest 都在同一檔內；manifest 透過 `data:` URL 動態掛入 ``，避免再多一個外部檔。

圖片策略

上載後先用 Canvas 壓縮成 JPEG，再存成 Data URL；優點是可直接打包進 JSON，但大量高解析圖片會增加資料庫容量。

安裝與離線限制

此版保留 Add to Home Screen 提示與 manifest 注入，但因沒有 Service Worker，不屬於完整離線 PWA 架構。
