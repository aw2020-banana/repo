🔧 技術資訊

本應用使用以下技術構建：

  • 📂 IndexedDB — 所有餐廳、食物、地段和菜式資料均儲存於瀏覽器內建的 IndexedDB 資料庫，支援大容量離線資料。
  • 🔒 Storage Persistence API — 使用 navigator.storage.persist() 申請持久化儲存，防止瀏覽器在磁碟空間不足時自動清除資料。
  • ⚙️ Service Worker — 完整緩存所有資源，支援離線使用。首次載入後即使無網絡連接，應用依然完全可用。
  • 📱 PWA (漸進式網絡應用) — 可添加到主畫面，以應用形式運行，支援全螢幕模式。
  • 📸 圖片儲存 — 食物相片以 Base64 格式直接儲存於 IndexedDB，無需服務器。
  • 💾 JSON 匯入/匯出 — 支援完整資料備份與跨設備遷移，包含所有餐廳、食物及相片資料。
