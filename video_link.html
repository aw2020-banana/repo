🔧 技術說明（點擊展開）

整體架構

單一 HTML 檔，沒有後端、沒有建置步驟。HTML + CSS + 原生 JavaScript，資料全部存在瀏覽器的 IndexedDB（資料庫 videoLinksDB，版本 1）。可直接放上 GitHub Pages。

資料結構

object store "videos"  (keyPath: id, autoIncrement)
{ id, url, title, platform, category, tags[], note,
  thumb, favorite, watched, createdAt, updatedAt }

object store "categories" (keyPath: name)
{ name }

影片以「分類名稱」關聯。改名時會在同一個 transaction 內同步更新所屬影片；刪除分類時，影片會變成「未分類」，不會被刪除。分類以 Intl.Collator('zh-Hant') 按名稱排序。新增影片時，分類以下拉選單選擇；選「＋ 新增分類…」才會出現輸入框，儲存時自動建立該分類。

自動擷取資料

純前端會受 CORS 限制，所以依序嘗試以下免 API Key 的公開服務，取得第一個有標題的結果：

1. YouTube oEmbed   (youtube.com/oembed)
2. Vimeo oEmbed     (vimeo.com/api/oembed.json)
3. noembed.com      (涵蓋多個平台)
4. microlink.io     (通用 Open Graph，有免費額度)

YouTube 縮圖可直接由影片 ID 組成 img.youtube.com/vi/ID/hqdefault.jpg。全部失敗時：標題 = URL 以「/」分隔的最後一段（不含 # 之後內容），平台 = https:// 後以「/」分隔的第一段（即網域）。第三方服務可能改版、限流或失效，屆時請手動輸入。

播放

YouTube（youtube-nocookie）、Vimeo、Bilibili（BV 號）會在彈窗內嵌入播放；其他平台只開新分頁。部分影片擁有者會禁止嵌入，此時請用「開啟」按鈕。

持久化儲存

啟動時呼叫 navigator.storage.persist()，避免瀏覽器在空間不足時自動清除資料。Chrome 會依使用情況／是否已安裝為 PWA 自動決定，Firefox 會彈出詢問，Safari 的支援有限。不論結果如何，建議定期使用「匯出」備份 JSON。清除網站資料會一併刪除 IndexedDB。

加到主畫面

Chrome／Edge／Android：監聽 beforeinstallprompt 後顯示安裝按鈕。iOS Safari 沒有此事件，改為顯示「分享 → 加入主畫面」的說明。Manifest 與圖示由 JavaScript 即時產生（Blob URL + canvas），方便維持單檔；若要最穩定的 PWA 安裝，可另放 manifest.json 與 sw.js，頁面偵測到 sw.js 存在時會自動註冊。

// sw.js（可選，離線開啟頁面）
const C='vlinks-v1';
self.addEventListener('install',e=>{
  e.waitUntil(caches.open(C).then(c=>c.addAll(['./'])));
  self.skipWaiting();
});
self.addEventListener('fetch',e=>{
  if(e.request.method!=='GET')return;
  e.respondWith(fetch(e.request).catch(()=>caches.match(e.request)
    .then(r=>r||caches.match('./'))));
});

匯入／匯出格式

{ "app":"video-links","version":1,"exportedAt":"ISO 時間",
  "categories":["分類A","分類B"],
  "videos":[ { "url":"https://…","title":"…","platform":"…",
               "category":"分類A","tags":["a","b"],"note":"",
               "thumb":"","favorite":false,"watched":false,
               "createdAt":1700000000000 } ] }

「合併」會略過 URL 已存在的影片；「覆蓋」會先清空現有資料。匯入時 id 會重新產生。

響應式設計

Mobile-first；卡片使用 grid-template-columns: repeat(auto-fill, minmax(250px,1fr))，手機單欄；縮圖與播放器用 aspect-ratio:16/9；按鈕最小高度 44px；支援 safe-area 與深色模式。
