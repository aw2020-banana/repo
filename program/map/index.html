技術說明（按需展開）

整體架構
單一 index.html，無後端、無建置步驟。地圖使用 Leaflet 1.9.4（CDN），底圖為 OpenStreetMap 等公開圖磚，不需要 API Key。使用者資料全部存在瀏覽器的 IndexedDB，頁面本身是靜態檔，可直接放在 GitHub Pages。
IndexedDB 資料結構
資料庫 static-map-db v1，物件倉庫 places（keyPath: id，autoIncrement）。欄位： 
{ id, name, cat, note, lat, lng, created, updated }
另有 settings 倉庫以 key/value 存放底圖、深色模式、最後視圖。所有操作以 Promise 包裝 transaction，寫入在 oncomplete 後才算成功。
JSON 匯入／匯出格式
匯出格式： 
{ "app":"static-map","version":1,
  "exported":"ISO 時間",
  "places":[{name,cat,note,lat,lng,...}] }
匯入同時接受：以上格式、純陣列、標準 GeoJSON FeatureCollection（只讀 Point）。匯入時會驗證經緯度範圍（lat ±90、lng ±180）、重新分配 id、未知分類歸入「其他」，並以合併方式加入，不會覆蓋現有資料。
持久化儲存 storage.persist()
瀏覽器預設的儲存是「盡力而為」，空間不足時可能被清除。本頁在載入及第一次儲存時呼叫 navigator.storage.persist()。Chrome 按網站使用情況自動決定（例如已安裝為 PWA、已加書籤），不一定彈窗；Firefox 會彈出權限提示；Safari 對已加入主畫面的網站較不易被清除。結果以 navigator.storage.persisted() 顯示，並以 estimate() 顯示用量。即使有持久化，仍建議定期匯出 JSON 備份。
Add to Home Screen 提示
Android / Chrome / Edge：監聽 beforeinstallprompt，攔截後在自訂橫幅按「安裝」時才呼叫 prompt()。iOS Safari 沒有此事件，所以偵測 iPhone/iPad 且非 standalone 時，顯示「分享 → 加入主畫面」的教學。已安裝（display-mode: standalone）或使用者按過「稍後」（記在 localStorage，7 天）則不再顯示。Manifest 與圖示由 JS 動態產生（Blob + canvas），以維持單檔。
離線與 Service Worker
Service Worker 必須是獨立的 JS 檔，不能由 Blob 或 HTML 內嵌註冊，所以單一 HTML 無法自帶。本頁會嘗試註冊同目錄的 sw.js：有則啟用離線（快取頁面、Leaflet 及已瀏覽過的圖磚），沒有也不影響使用，資料仍存在 IndexedDB，只是斷網時載入不到頁面及圖磚。需要 HTTPS（GitHub Pages 符合）。
響應式設計
viewport 設定、100dvh（避開手機網址列）、env(safe-area-inset-*)（瀏海安全區）。寬度 ≤760px 時，側欄變成底部抽屜，可收合；按鈕與勾選項目至少 44px 觸控大小；輸入欄字級 16px，避免 iOS 自動放大。
URL 分享與安全性
地圖位置同步到 #lat/lng/z，複製網址即可分享視圖。所有用戶輸入顯示前都經過 HTML 跳脫，避免匯入的 JSON 造成 XSS。OSM 公共圖磚有使用政策，不適合大流量；如需，請改用自己的圖磚服務。
